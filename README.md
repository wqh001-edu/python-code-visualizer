## ✨ 功能特性

- **🎯 实时代码编辑器** - 基于 Monaco Editor 的 Python 代码编辑器，支持语法高亮、自动补全
- **⚡ 逐步执行可视化** - 逐步执行代码，实时可视化变量变化、内存状态和执行流程
- **📊 动态可视化面板** - 显示执行栈、变量作用域、内存对象引用关系
- **🔧 完整调试功能** - 支持运行、暂停、步进、重置等调试操作
- **🛡️ 安全执行环境** - Docker 容器隔离，过滤危险代码，保障服务器安全
- **📱 响应式设计** - 适配桌面端和移动端设备
